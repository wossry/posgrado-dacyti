GUÍA PARA EJECUTAR LA WEB DESDE VISUAL STUDIO CODE
===================================================

PROYECTO: Sistema de Gestión de Posgrado DACYTI (Vite + React + Tailwind v4)
CARPETA  : /home/kev/pro_posgrado/posgrado-dacyti


1) REQUISITOS PREVIOS (ya instalados en esta máquina)
------------------------------------------------------
- Node.js y pnpm instalados por pacman.
- IMPORTANTE: usar SIEMPRE pnpm, nunca npm.


2) PASOS PARA LEVANTAR LA WEB
-----------------------------
1. Abre Visual Studio Code.
2. Menú "File" > "Open Folder..." y selecciona la carpeta:
     /home/kev/pro_posgrado/posgrado-dacyti
   (o desde terminal:  code /home/kev/pro_posgrado/posgrado-dacyti)

3. Abre la terminal integrada de VSCode:
   - Menú "Terminal" > "New Terminal", o atajo Ctrl+Ñ

4. Instala las dependencias (SOLO la primera vez):
     pnpm install

5. Arranca el servidor de desarrollo (modo demo):
     pnpm dev

6. Verás algo como:  Local: http://localhost:5173
   Presiona Ctrl + clic sobre esa URL (o cópiala al navegador).

7. Para DETENER el servidor: presiona Ctrl+C dentro de la terminal.


3) SI QUIERES LA VERSIÓN "DE PRODUCCIÓN" (build optimizado)
-----------------------------------------------------------
1. Detén el servidor con Ctrl+C.
2. Ejecuta:
     pnpm build
3. Luego:
     pnpm preview
   Esto sirve el build en http://localhost:4173 y NO necesita el server de dev.


4) NOTAS
--------
- No uses npm (aunque "npm run dev" funcione, el proyecto está hecho para pnpm).
- Después de cambiar código, la página se actualiza sola (HMR).
- Si algo no compila, el error sale en la terminal; el botón "Cerrar sesión"
  es solo visual (la página de login no valida credenciales reales).


5) EXTENSIONES DE VSCode
-------------------------
NO necesitas nada para ejecutar la web: Node + pnpm son suficientes.

PERO TE RECOMIENDO instalarlas para autocompletado y estilos:

 OBLIGATORIA (la más importante):
 - Tailwind CSS IntelliSense  ->  buscar: "Tailwind CSS IntelliSense" de Brad Cornes
   Da autocompletado de clases y colores/dark mode (soporta Tailwind v4).

 MUY RECOMENDADAS:
 - Prettier - Code formatter  ->  "Prettier" de Prettier
   Formatea el código al guardar (Settings > Format on Save = ON).
 - ESLint                      -> "ESLint" de Microsoft
   El proyecto usa oxlint vía "pnpm lint"; ESLint sirve de respaldo.
 - OPCIONAL: oxlint          -> "oxc" (linguist135)
   Linter nativo de oxc, corre el mismo "pnpm lint".
 - ES7+ React/Redux snippets  -> "ES7+ React/Redux/React-Native/ReactJS snippets"
   Atajos para escribir componentes React rápido.

 CÓMO INSTALARLAS:
   Menú Extensions (Ctrl+Shift+X) > busca el nombre > botón "Install".

 Para activar Prettier al guardar:
   Ctrl+Shift+P > "Preferences: Open Settings (JSON)" y agrega:
     "editor.formatOnSave": true,
     "editor.defaultFormatter": "esbenp.prettier-vscode"

¡Listo! Con eso abres la carpeta, ejecutas "pnpm dev" y tu página corre en VSCode.
